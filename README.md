# Seat-Sync

Early-stage concept: a registry where test centers publish accommodation
capacity (private rooms, screen readers, scribes, extended time, and so on)
by date, exposed through an API so exam delivery vendors can search across
centers instead of calling each one to ask what they can support.

This repo currently holds only the concept landing page (`index.html`),
published via GitHub Pages for early feedback. No product code yet.

**Status:** validating the problem with test centers and delivery vendors
before building anything. Not a company, not a funded project.

**Contact:** seatsync9@gmail.com

## Hosting

This is a static page — enable GitHub Pages on this repo
(Settings → Pages → deploy from the `main` branch, root folder) and
`index.html` will serve directly.
